I am not a developer. I built an app with an AI coding agent and I need a server with a database and user accounts. What should I use?
웹 검색

If you’re not a developer and just want a simple, scalable server, database, and user accounts, use a managed backend platform that handles hosting, authentication, and data storage for you.

Direct recommendation:

Supabase: provides a Postgres database, authentication, and auto-generated APIs in one dashboard. Great for web apps and simple to set up.

Firebase (with Firestore or Realtime Database) is another solid option, especially if you’re targeting mobile and need real-time features.

Why these are good for non-developers:

End-to-end managed services with out-of-the-box auth and database.

Free tiers or affordable starts for small apps.

Documentation and community support to guide you through setup without writing server code.

Other concepts to consider:

If you want to stay fully no-code, consider AI-assisted builders that bundle backend hosting, database, and auth in one package.

For hosting the frontend, you can pair these backends with a simple static site hosting service.

Key questions to decide:

Do you need real-time data and mobile-specific features? Firebase might be preferable.

Do you want a familiar SQL database with strong relational capabilities? Supabase (Postgres) is a good fit.

Do you plan to scale later or need more fine-grained access control? Look for built-in role-based access control and row-level security in the backend you choose.

If you’d like, tell me your app’s rough data model (types of users, key data stored, and any auth requirements), and I’ll map out a concrete setup plan using one of these platforms.
