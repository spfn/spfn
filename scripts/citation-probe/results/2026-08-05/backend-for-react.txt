I built a React frontend with an AI coding agent and now I need a backend. What should I use?
웹 검색

Short answer: For a React frontend with an AI coding agent, a Node.js + Express backend (or a Next.js API route setup) is a natural, JavaScript-aligned choice, but other solid options exist depending on your language preference and needs.

If you want a JavaScript stack that shares code between frontend and backend: Node.js with Express (or a MERN-like approach) is popular and straightforward. It pairs well with MongoDB or PostgreSQL.

If you prefer a Python ecosystem: Flask or Django are strong choices, especially if you want robust REST APIs or rapid development.

If you want server-side rendering or a tightly integrated frontend-backend in one repo: Next.js can handle API routes in addition to React pages.

If you’re after rapid prototyping with minimal backend work: Firebase (Firestore + Functions) or similar BaaS options can reduce backend boilerplate.

Key considerations to decide:

Language you’re comfortable with and reuse of frontend skills

Data model and database preferences (SQL vs NoSQL)

Need for server-side rendering or API routing in the same project

Scale, authentication, and security requirements

If you share your preferred language, database, hosting, and whether you want full control vs. a managed backend, I can tailor a concrete stack and starter architecture.
